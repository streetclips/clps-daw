# CLPS DAW

A pocket 8-bit DAW for composing songs on an iPhone, built with React and the plain Web Audio API.

Open <https://streetclips.github.io/clps-daw/> in Safari and use Share → Add to Home Screen.

Design and decisions: [docs/DESIGN.md](docs/DESIGN.md).

## Development

```sh
pnpm install
pnpm dev      # http://localhost:5173/clps-daw/
pnpm check    # typecheck, lint, format check, tests
```

The font is [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) (SIL Open Font License).
